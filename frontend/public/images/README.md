# Optional pictures (Freepik)

The site works without any pictures. These optional slots only add a faint photo behind the "Who SignSpell is for" cards on the
landing page. Save a download with the exact name and it appears. Check each file's licence (the free Freepik licence asks you to credit the author).

| File | Card | Freepik search terms |
| --- | --- | --- |
| role-learners.jpg | Learners | "learning sign language", "student webcam" |
| role-teachers.jpg | Teachers and donors | "teacher inclusive classroom", "sign language teacher" |
| role-admins.jpg | Admins | "admin dashboard", "team computer" |
| role-privacy.jpg | Everyone | "privacy", "secure data" |

Use landscape images around 1200x800, JPG, under 250 KB. Sign pictures themselves (the reference photo for each letter, word or sentence)
are uploaded by teachers and admins in the app and stored on Cloudinary by your backend.
